# ADR-0003 Implementation: F3–F6

**Date:** 2026-03-12

## Task

Complete ADR-0003 reliability and ergonomics refactor — F3 through F6. F1 (structured errors), F2 (persistent task registry), and F3's relay.py changes were already committed.

## Changes

- **`maestro/tools/fleet.py`** — Added `get_transfer_token` MCP tool (F3) issuing 5-min ephemeral bearer tokens via `register_ephemeral_token`. Added `allowed_dirs` validation in `codex()`, `claude()`, `gemini()` that rejects `working_dir` outside the host's allowed prefixes (F4). Added optional `timeout: int = 0` parameter to all three dispatch tools, defaulting to config values (F5). Updated all tool docstrings to steer agents away from `exec()` for dispatch work (F6).
- **`maestro/hosts.py`** — Added `allowed_dirs: list[str]` field to `HostConfig` dataclass, parsed from YAML (F4).
- **`maestro/config.py`** — Changed hardcoded 600s agent timeouts to env-configurable defaults: codex=1800s, gemini=900s, claude=1200s (F5).
- **`hosts.example.yaml`** — Added `allowed_dirs` documentation and examples for workstation and windows-pc entries (F4).

## Decisions

- `allowed_dirs` uses simple string prefix matching (`startswith`) rather than path resolution — keeps it predictable for cross-platform paths (Windows backslashes, WSL paths).
- `timeout` parameter uses `0` as sentinel for "use config default" rather than `None` to keep MCP schema simple (integer vs optional).

## Surprises

- None. All changes were additive, no signature breakage.
